# Prepare a garage permit package

Planform supports a detached, rectangular, single-storey garage with a gable roof. Start with the drawing you intend to submit. If the project contains proposals, select the garage proposal before opening **Export → Garage permit**. The permit inputs belong to that drawing and are saved in the editable project.

1. **Floor plan.** Draw or open a closed rectangle. The wall endpoints are centerlines, so for a 6 × 7 m exterior with 20 cm walls use a 580 × 680 cm centerline rectangle. Check **Show exterior wall lengths** in Properties. **Export → PDF · scaled sheet** opens the standalone sheet preview. Choose A4 or A3 and the drawing scale, then print the PDF at 100% actual size.
2. **Building areas.** Confirm the measurable ground floor, loft, roof overhang and any additional countable area. The panel shows the two wall-face boundaries and explains provisional values. The building calculation covers the garage. Calculate plot utilization separately when the property includes other structures or outdoor parking. [DiBK on BRA](https://www.dibk.no/regelverk/byggteknisk-forskrift-tek17/5/5-4) · [DiBK on BYA](https://www.dibk.no/regelverk/byggteknisk-forskrift-tek17/5/5-2)
3. **Section and elevations.** Enter the finished floor level, clear wall height, roof pitch and roof thickness. Set opening heights and window sills. Enter an existing and proposed terrain profile for each view using one station and height pair per line in centimetres. The station increases from the left side of the view and the height uses the same datum as the floor level. Use the A–A marks to locate the section. The elevation names follow the four sides of the plan.
4. **Site plan.** Import a local image or select a page of a local municipal PDF. Pick both ends of a known scale bar and enter its distance in metres. Place the centre of the garage, set its rotation and the map's north direction, and mark nearby boundaries, roads, buildings or other relevant features. The site plan measures shortest horizontal distances from the garage exterior to marked features. Record any survey or projection corrections in the corresponding feature note. Enter the property identifier on **Application package** before downloading the site sheet.
5. **Application package.** Enter the property and project description. Mark separately prepared documents as supplied, missing or not applicable. Download the ZIP and review the editable text draft and the checklist. Available drawings, the area calculation and outstanding items are listed inside. The package rebuilds from the selected garage at export time, with a 1:100 floor plan, section and elevations, and a 1:500 site plan. [Levanger documentation guide](https://www.levanger.kommune.no/tjenester/arealplan-byggesak-kart-brann-og-eiendom/byggesak/soke-om-byggetiltak-pa-egenhand/)

Save the editable `.planform.json` to retain the calibrated map and permit inputs. Maps and tracing references are embedded as local PNG or JPEG, with up to 100 PDF pages from which to select, 24 MB per source file, 24 million source image pixels, and 6 million embedded pixels. On floor-plan tracing references, **Calibrate scale** rescales the whole drawing, including its tracing image. The site map uses independent calibration.

For a downloaded static application build, extract the ZIP to a directory and serve the extracted files from a static server. A local example is `python3 -m http.server --bind 127.0.0.1 8000` from the extracted directory, then open [localhost:8000](http://127.0.0.1:8000/). The application processes local files and generates downloads in the browser.
