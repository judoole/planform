# Place a building on a property

1. Draw the outside walls in **Floor plan**. A new drawing already uses centimeters. Use a closed outline with straight walls and no inward corners so the shared building model can find its outside edge.
2. Open **Map**. Search for a street address with its town, or enter the municipality with the property number, for example `315/204 Levanger`. You can also enter the full cadastral number `5037-315/204`.
3. Select the result and click **Place building**. Drag the outline to move it. Drag the white handle to rotate, or enter an angle in degrees. Use the zoom buttons to see the site in more detail.
4. Save the editable project to keep the selected property and placement. Resizing the floor plan keeps the building centered on the same location at the same angle.
5. In **Export**, select **Property map** among the PDF pages and preview it. The map prints at 1:500 on paper at 100% actual size. Its background uses Kartverket’s parcel data and the dialog shows this choice when the detailed on-screen background is selected.

The **Background** picker preserves the map view and building placement. **Property map** shows streets, buildings and parcel outlines where available. **Parcel boundaries** shows the data used in the PDF. **Aerial photo** is unavailable pending a browser-accessible source with suitable terms. An existing imported site map is still accessible from **Open imported map**.

The static app calls Kartverket and Geonorge directly. The editable drawing stores the selected property and a geographic center and rotation for its footprint. It stores no basemap, parcel response, provider URL, or credential. Requests for search and map coverage reach those public services. A saved placement reopens offline, and the app shows when it cannot retrieve boundaries or a background.

The parcel API can omit boundaries or return incomplete geometry. The distance is the shortest horizontal distance from the outside wall to the selected mapped parcel boundary. Boundary quality varies and mapped measurements are approximate. Roads and buildings in the topographic view are visual context. The printable map contains cadastral geometry and uses a fixed-scale crop around the building. Nearby context comes from a capped query around the selected property or placed building. Google Maps is a follow-up.
