# Planform

A simple floor planner that runs on a static web page. Save editable plans as JSON, export scaled drawing PDFs, and assemble a detached-garage permit draft and attachment ZIP in the browser.

See the fully functional page at [https://judoole.github.io/planform/](https://judoole.github.io/planform/).

Documentation: [Getting started](docs/getting-started.md) · [Drawing and editing](docs/drawing-and-editing.md) · [Save, share, and compare](docs/projects.md) · [Agent workflow](docs/agent-workflow.md) · [File format](docs/file-format.md) · [Development](docs/development.md).

For garages, open **Export → Garage permit**. See the [garage permit workflow](docs/garage-permit.md) for measurements, map calibration and attachments.
